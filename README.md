# security-homelab
**Multi-VM security lab for penetration testing and system hardening practice**

This is the tracking of my cybersecurity focused home lab process. I will be engaging in penetration testing like nmap scanning and other tools. On the flip side, I will be practicing how to defend a system. The environment consists of an Ubuntu, and Kali. The Ubuntu is the main server and victim. Kali is the attacker.

### The exercises are marked by (#) and they show the process, reflections, and learnings. If any errors occured they will not be in the exercise, but detailed in Extended_Documentation. It sometimes has more information than the exercise depending on various factors.

>Check **Project-Security-Lab** for details about the environment, and check **(1)Scanning with nmap** for the first exercise.
